# Purge

<div dir="rtl">

**منظّف ملفات آمن لنظام macOS — صغير، محلي بالكامل، ويُحذف من دون أن يترك أثرًا.**

تطبيق أصلي مكتوب بلغة Swift و SwiftUI. يُبنى بأمر واحد من دون الحاجة إلى Xcode.

## الفكرة الأساسية

معظم برامج التنظيف على الماك تطلب كلمة مرور المسؤول، وتشتغل بصلاحيات `root`، وتحذف أشياء لا تراها. Purge بُني على العكس تمامًا:

| القاعدة | التفصيل |
|---|---|
| لا `sudo` أبدًا | لا يطلب كلمة مرور، ولا يشتغل كمسؤول. لو احتاج صلاحية لا يملكها، يتوقف ويخبرك. |
| مجلد المنزل فقط | لا يلمس شيئًا خارج `~` — الاستثناء الوحيد تطبيق اخترت أنت إلغاء تثبيته. |
| قائمة بيضاء أولًا | لا يستطيع العثور إلا على ما هو مكتوب صراحةً في `Sources/Rules.swift`. |
| بوابة واحدة للحذف | كل عملية حذف تمرّ عبر `SafetyGuard.approve()`. لا يوجد مسار ثانٍ. |
| ترى كل ملف | لا يُحذف شيء قبل أن يظهر في القائمة بحجمه ومساره. |
| لا اتصال بالشبكة | الطلب الوحيد هو فحص الإصدار على GitHub، وأنت من يضغط الزر. |
| لا عملية خلفية | لا وكيل تشغيل، ولا عنصر بدء تشغيل، ولا مساعد خفي. |

## ما الذي يُنظّفه

**تنظيف أساسي**
ذاكرة التخزين المؤقت للتطبيقات، كاش التطبيقات المعزولة (sandboxed)، السجلات، تقارير الأعطال، الملفات المؤقتة، بقايا التحديثات، حالة النوافذ المحفوظة، كاش مرفقات البريد، مصغّرات Quick Look.

**بيانات المتصفحات**
Safari، Chrome، Edge، Brave، Firefox — ملفات الكاش فقط. **لا يلمس** كلمات المرور، الإشارات المرجعية، السجل، الكوكيز، أو تسجيلات الدخول.

**مخلفات المطورين**
Xcode DerivedData والأرشيفات ودعم الأجهزة، محاكيات iOS، وكاش npm و yarn و pip و Homebrew و CocoaPods و Go و Rust و Gradle و SwiftPM.

**أدوات إضافية**
- **Large & Old Files** — يعرض ما يستهلك المساحة فعلًا، وتختار أنت.
- **Duplicates** — ملفات متطابقة بايت ببايت، مُتحقَّق منها بـ SHA-256 كاملة، وتُبقى دائمًا أقدم نسخة.
- **Uninstaller** — يحذف أي تطبيق مع كل ملفاته المتبقية في مكتبتك.
- **Startup Items** — يعرض ما يبدأ عند تسجيل الدخول، ويسمح بتعطيله.

## البناء

تحتاج فقط إلى Command Line Tools (حوالي ٢٠٠ ميجابايت)، وليس Xcode كاملًا:

```bash
xcode-select --install
```

ثم:

```bash
./build.sh --install
```

يبني التطبيق وينسخه إلى `/Applications` ويفتحه. لبناء فقط من دون تثبيت، استخدم `./build.sh`.

**أول تشغيل:** سيقول macOS إن المطوّر غير موثوق، لأن التطبيق موقّع توقيعًا ذاتيًا (ad-hoc) لا بحساب مطوّر مدفوع. اضغط بالزر الأيمن على التطبيق ← Open ← Open. مرة واحدة فقط.

**Full Disk Access (اختياري):** من دونه تبقى بعض المجلدات المحمية غير مرئية لـ Purge. التطبيق يعرض زرًا يأخذك مباشرة إلى الإعداد إن أردت.

## التحديث

**من داخل التطبيق:** افتح Updates، اضبط اسم المستخدم والمستودع على GitHub، ثم اضغط Check.
يقرأ Purge آخر إصدار منشور، ينزّل ملف zip المرفق به، ويتحقق من أن مُعرّف الحزمة مطابق وأن الإصدار أحدث فعلًا — وإن فشل أي من الفحصين لا يُثبَّت شيء. الاستبدال يحدث بعد خروج التطبيق، وإن تعثّر تُعاد النسخة السابقة مكانها.

**من المصدر:**

```bash
./update.sh --install
```

**لنشر إصدار جديد:**

```bash
./scripts/release.sh 1.0.1
```

يرفع رقم الإصدار، يعمل commit و tag و push. بعدها يبني GitHub Actions التطبيق تلقائيًا ويرفق ملف zip بالإصدار — وهو ما يبحث عنه المحدّث داخل التطبيق.

## الحذف الكامل

من داخل التطبيق: **Settings ← Uninstall Purge**. يعرض لك أولًا القائمة الكاملة لكل ما كتبه على جهازك، ثم ينقلها إلى سلة المهملات مع التطبيق نفسه ويخرج.

أو من الطرفية:

```bash
./uninstall.sh
```

بصمة Purge كاملة على جهازك — لا شيء غير هذه المسارات:

```
/Applications/Purge.app
~/Library/Application Support/Purge/
~/Library/Preferences/com.novamira.purge.plist
~/Library/Caches/com.novamira.purge
~/Library/Saved Application State/com.novamira.purge.savedState
```

## ملاحظة على "Move to Trash"

الإعداد الافتراضي ينقل الملفات إلى سلة المهملات، وهو قابل للتراجع — لكنه **لا يحرّر المساحة** حتى تُفرّغ السلة. إن كان هدفك استرجاع المساحة فورًا، غيّر الإعداد إلى `Delete permanently` من Settings. التطبيق يذكّرك بهذا بعد كل عملية.
